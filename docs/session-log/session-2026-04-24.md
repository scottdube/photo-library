# Session 2026-04-24 — Phase 0 Validation

## Summary

Validated CLIP-based semantic photo search against the full Photos library on Mac Mini using rclip. Result: **viable.** Top-3 relevance across 8 representative queries was approximately 80%, including strong performance on shop/CNC content that Photos.app cannot find. Phase 0 success criteria met; architecture from project charter is greenlit.

## Setup

**Indexing tool:** rclip 2.1.6 (installed via `uv tool install rclip`)
**Model:** Default OpenCLIP (base CLIP architecture, ~600MB)
**Photo set:** 17,866 symlinked photos from `~/Pictures/Photos Library.photoslibrary/originals` (filtered: only-photos, not-hidden, not-shared)
**Index location:** `~/photo-library-subset/photos-symlinks/.rclip/`
**Indexing duration:** 27 minutes 44 seconds (~10.74 images/sec on Mac Mini M4)
**Disk usage:** Symlinks only; embedding cache ~1GB total

## Methodology

1. Extracted local photo paths from Photos library via `osxphotos query --only-photos --not-hidden --not-shared`
2. Filtered to local paths only (excluded ~1,452 iCloud-only entries that returned `None`)
3. Created symlink farm to avoid copying ~90GB of photos
4. Ran rclip indexing pass to generate CLIP embeddings for all 17,866 photos
5. Ran 8 representative test queries spanning general and shop-specific content
6. Visually evaluated top-3 results for each query

## Key findings

**CLIP works at scale for this library.** The screenshot/label dominance observed in the earlier 500-photo test disappeared with the full set — real relevant content outnumbers the noise floor when there are enough genuine matches in the index.

**Shop content is findable.** "CNC milling machine" surfacing CNC lathes, manual lathes, and CNC mills is the highest-value finding. This content is invisible to Photos.app's built-in search and represents the primary motivating use case for this project.

**Visual semantic reasoning works.** "Fixture plate with grid of holes" returning a welding fixture table and grid floor mat (in addition to actual fixture plate content) demonstrates CLIP doing concept-level matching rather than keyword matching. Useful capability that Photos.app's keyword-based search fundamentally cannot replicate.

**Vague queries still return vague results.** "Golf course green grass" returned more general grass than golf-specific content. Specificity in phrasing improves results — same as web search.

## Known issues

**rclip matmul warnings persist.** `RuntimeWarning: divide by zero / overflow / invalid value encountered in matmul` appears on every query. Occurs in `rclip/model.py:218` during similarity computation. Does not appear to corrupt results — top-ranked photos are consistently relevant. Likely caused by edge cases in a small number of embeddings (possibly very dark images, very small images, or HEIC variants that decode to mostly-uniform pixels). Worth investigating eventually but not blocking.

**Some photos remain iCloud-only.** ~1,452 photos in the library returned `None` for filepath via osxphotos. Not yet investigated whether "Optimize Mac Storage" is the cause, or whether these are recent additions still syncing. Will need to address before full-library production indexing.

**Text-heavy images get artificially high baseline scores.** Screenshots, photos of computer screens, equipment labels, and document photos rank moderately well for many queries due to CLIP's known "text shortcut" behavior. With abundant relevant content (full library), they get pushed down in rankings, but they will pollute results when querying for concepts where the library has few true matches. Future work: filter screenshots at index time or query time.

## Decisions

**[DECISION] Phase 0 verdict: proceed with project as charted.** Base CLIP via rclip provides usable semantic search across both general and shop-specific content. No need to pivot to SigLIP or other models at this stage.

**[DECISION] Defer screenshot filtering to future iteration.** Implementation complexity not justified at Phase 0 since real content outranks screenshots at full library scale.

**[DECISION] Defer matmul warning investigation.** Cosmetic noise; results are valid. Re-evaluate if specific query patterns fail in production.
